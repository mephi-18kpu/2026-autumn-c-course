# Занятие 6. Рекурсия

## Базовый случай и рекурсивный шаг

**Рекурсия** — способ решения задачи, при котором функция вызывает себя для решения более простого случая той же задачи. В наших примерах задача упрощается за счёт уменьшения аргумента.

- **Базовый случай** завершает вызов без дальнейшей рекурсии.
- **Рекурсивный шаг** сводит задачу к меньшей и приближает её к базовому случаю.

Чтобы вызовы завершились, базовый случай должен быть достижим из каждого допустимого начального состояния.

## Обратный отсчёт

Функция `print_countdown` принимает неотрицательное целое число. Если число равно нулю, функция завершается. Иначе она печатает текущее число и вызывает себя с аргументом на единицу меньше.

```c
#include <stdio.h>


void print_countdown(int number);


int main(void){
    print_countdown(3);

    return 0;
}


void print_countdown(int number){
    if (number == 0){
        return;
    }

    printf("%d\n", number);
    print_countdown(number - 1);
}
```

Вызовы идут в порядке `print_countdown(3) → print_countdown(2) → print_countdown(1) → print_countdown(0)`. Печать происходит перед следующим вызовом, на рекурсивном спуске.

```text
3
2
1
```

## Рекурсивный спуск и возврат

**Рекурсивный спуск** — последовательность вызовов от первого вызова до базового случая. **Рекурсивный возврат** начинается, когда базовый вызов завершается и управление последовательно передаётся обратно вызывающим функциям.

Первому вызову рекурсивной функции присвоим уровень `0`. Каждый следующий вложенный вызов увеличивает уровень на единицу.

У каждого вызова своё значение параметра `number`. Пока выполняется вложенный вызов, предыдущий ждёт его завершения. Когда выполнение доходит до базового случая, стек вызовов можно представить так.

```text
Вершина стека
    print_countdown(0)  ← базовый случай
    print_countdown(1)  ← ждёт завершения вызова с 0
    print_countdown(2)  ← ждёт завершения вызова с 1
    print_countdown(3)  ← ждёт завершения вызова с 2
    main
```

После `return` из вызова с аргументом `0` управление возвращается к вызову с аргументом `1`, к месту сразу после рекурсивного вызова. Затем завершаются вызовы с аргументами `2` и `3`. Это порядок LIFO. Последний начавшийся вызов завершается первым.

Поменяем местами печать и рекурсивный вызов в той же функции.

```c
void print_countdown(int number){
    if (number == 0){
        return;
    }

    print_countdown(number - 1);
    printf("%d\n", number);
}
```

Порядок вызовов сохраняется. Теперь печать происходит на рекурсивном возврате. После базового случая сначала напечатается `1`, затем `2` и `3`.

```text
1
2
3
```

Действия можно выполнять и на спуске, и на возврате. Если печатать число до и после рекурсивного вызова, при аргументе `3` получим последовательность `3, 2, 1, 1, 2, 3`.

## Сумма элементов массива

В [занятии 5](Занятие%205.md) мы передавали в функцию адрес начала массива и количество элементов отдельно. Используем тот же интерфейс. Функция `sum_array` считает сумму первых `count` элементов. По правилам вызова `count` лежит в пределах от нуля до количества элементов массива.

- **Базовый случай.** При `count == 0` элементов для сложения нет. Возвращаем `0`.
- **Рекурсивный шаг.** Сначала находим сумму первых `count - 1` элементов. Затем прибавляем элемент с индексом `count - 1`.

Адрес начала массива во всех вызовах один и тот же. Уменьшая `count`, мы сокращаем обрабатываемую часть массива на один элемент. Проверка базового случая стоит перед обращением к элементу и исключает обращение по индексу `-1` при `count == 0`.

```c
#include <stdio.h>

#define ARRAY_SIZE 3


int sum_array(const int numbers[], int count);


int main(void){
    int numbers[ARRAY_SIZE] = {4, 2, 7};

    printf("Sum: %d\n", sum_array(numbers, ARRAY_SIZE));

    return 0;
}


int sum_array(const int numbers[], int count){
    if (count == 0){
        return 0;
    }

    int partial_sum = sum_array(numbers, count - 1);

    return partial_sum + numbers[count - 1];
}
```

Таблица трассировки показывает, как меняется `count` на спуске и какое значение возвращает каждый вызов. Столбец спуска читайте сверху вниз, а столбец возврата — снизу вверх.

| Уровень | Рекурсивный спуск | Рекурсивный возврат |
| ---: | --- | --- |
| 0 | `count = 3`, вызов с `count = 2` | `6 + numbers[2] = 13` |
| 1 | `count = 2`, вызов с `count = 1` | `4 + numbers[1] = 6` |
| 2 | `count = 1`, вызов с `count = 0` | `0 + numbers[0] = 4` |
| 3 | `count = 0`, базовый случай | `0` |

Программа выведет `Sum: 13`. Для этой реализации каждая промежуточная сумма должна помещаться в тип `int`.

## Глубина рекурсии

**Глубина рекурсии** — максимальный уровень, достигнутый при вычислении. При суммировании `count` элементов глубина равна `count`, а максимальное число одновременно активных вызовов `sum_array` равно `count + 1`. В это число входит первый вызов на уровне `0`. В обычной реализации расход памяти стека растёт с глубиной рекурсии. При слишком большой глубине стек может переполниться.

Если максимальная глубина известна по входным данным, проверьте её перед первым вызовом. Например, для массива из трёх элементов `sum_array` потребуется четыре вызова одновременно, включая базовый. Допустимый предел выбирают с учётом размера стека, размера кадра функции и места, уже занятого другими вызовами.

Если глубину заранее трудно оценить, передавайте в функцию число оставшихся разрешённых рекурсивных шагов. В базовом случае возвращайте результат как обычно. Если нужен ещё один вызов, сначала проверьте остаток. При нуле сообщите о превышении предела, иначе передайте следующему вызову остаток на единицу меньше.

Цикл `for` для той же суммы выполняет столько же сложений и суммирует элементы в одном вызове функции.

При разборе рекурсивной функции проверьте, на каких аргументах она завершается, как каждый шаг приближает её к базовому случаю и какие действия выполняются при возврате.

## Самостоятельная работа 1 — факториал и трассировка

Напишите рекурсивную функцию для вычисления факториала. Пользователь вводит неотрицательное целое `n`. Для результата используйте тип `long`. Базовый случай — `0! = 1`. Для положительного `n` используйте соотношение `n! = n × (n - 1)!`.

### Заголовок `<limits.h>`

`<limits.h>` — заголовочный файл стандартной библиотеки C с макросами, значения которых зависят от реализации C.

| Макросы | Что задают |
| --- | --- |
| `CHAR_BIT` | Число битов в байте |
| `CHAR_MIN`, `CHAR_MAX` | Минимум и максимум `char` |
| `SCHAR_MIN`, `SCHAR_MAX`, `UCHAR_MAX` | Границы `signed char` и максимум `unsigned char` |
| `SHRT_MIN`, `SHRT_MAX`, `USHRT_MAX` | Границы `short` и максимум `unsigned short` |
| `INT_MIN`, `INT_MAX`, `UINT_MAX` | Границы `int` и максимум `unsigned int` |
| `LONG_MIN`, `LONG_MAX`, `ULONG_MAX` | Границы `long` и максимум `unsigned long` |
| `LLONG_MIN`, `LLONG_MAX`, `ULLONG_MAX` | Границы `long long` и максимум `unsigned long long` |

Минимум любого беззнакового целочисленного типа равен `0`. Для проверки факториала подключите `#include <limits.h>` и используйте `LONG_MAX`.

### Проверка переполнения

Для положительного `n` произведение `n × (n - 1)!` выйдет за пределы типа `long`, если `(n - 1)!` больше `LONG_MAX / n`. Проверяйте это условие перед умножением. При `n = 0` сразу применяется базовый случай.

Проверьте диапазон до первого рекурсивного вызова, чтобы глубина не зависела от произвольно большого ввода. Начните с `0! = 1` и последовательно проверяйте умножения на числа от `1` до `n`. Если очередное произведение превысило бы `LONG_MAX`, выведите `overflow` и завершите программу. Если `n!` помещается в `long`, вычислите его рекурсивно с трассировкой.

### Трассировка

Выведите трассировку вычислений в порядке выполнения. Для каждой строки укажите, какой это этап, текущий уровень и значение `n`. На возврате дополнительно выведите вычисленный факториал для этого вызова. Первый вызов имеет уровень `0`. Строку спуска печатайте при входе в функцию, а строку возврата — после вычисления результата, включая базовый случай.

Пример трассировки для `n = 3`.

| Этап | Уровень | `n` | Результат вызова |
| --- | ---: | ---: | ---: |
| Спуск | 0 | 3 | |
| Спуск | 1 | 2 | |
| Спуск | 2 | 1 | |
| Спуск | 3 | 0 | |
| Возврат | 3 | 0 | 1 |
| Возврат | 2 | 1 | 1 |
| Возврат | 1 | 2 | 2 |
| Возврат | 0 | 3 | 6 |

Проверьте также `n = 0`. Ожидается один вызов на уровне `0` и результат `1`.

Проверьте обе стороны границы диапазона. Например, если `LONG_MAX = 2147483647`, то `12! = 479001600` помещается в `long`, а при `n = 13` программа должна вывести `overflow`.

## Самостоятельная работа 2 — функция двух аргументов

Напишите программу, которая рекурсивно вычисляет `F(n, m)`. Введите два неотрицательных целых числа, каждое с новой строки. Для аргументов и результата используйте тип `unsigned long`.

### Правила вычисления

- Если `n + m` нечётно, функция возвращает меньшее из двух чисел. Это базовый случай.
- Если `n + m` чётно, вычисляем середину `middle = (n + m) / 2` и складываем результаты двух вызовов `F(middle, m)` и `F(n, middle)`.

### Разбор примера

У `F(5, 3)` сумма аргументов равна `8`, а середина равна `4`. Оба вложенных вызова сразу попадают в базовый случай. На дереве вызовов видно, какие значения они возвращают.

```text
F(5, 3) → 7       уровень 0
├─ F(4, 3) → 3    уровень 1
└─ F(5, 4) → 4    уровень 1
```

После возврата из обеих ветвей вызов `F(5, 3)` складывает `3` и `4`. Всего было три вызова, а глубина рекурсии равна `1`, поскольку обе ветви находятся на одном уровне. При контроле глубины с пределом сравнивают уровень очередного вложенного вызова.

При равных аргументах середина совпадает с каждым из них. Например, `F(4, 4)` снова вызывает `F(4, 4)` с той же парой, и вычисление зацикливается. Этот случай можно обнаружить до первого вызова. При разных аргументах на каждом рекурсивном шаге разность между большим и меньшим числом уменьшается вдвое. Спуск заканчивается, когда сумма аргументов становится нечётной.

### Формат вывода

Выведите одну строку с результатом.

- `endless` при равных аргументах, для которых рекурсивный вызов повторяет исходную пару.
- `overflow`, если сумма аргументов или сумма результатов вложенных вызовов выходит за диапазон типа. Проверяйте возможность сложения до выполнения операции. Верхняя граница типа доступна как `ULONG_MAX` из `<limits.h>`.
- Значение `F(n, m)` во всех остальных случаях.

Примеры проверок.

| `n` | `m` | Вывод |
| ---: | ---: | --- |
| 5 | 3 | `7` |
| 4 | 4 | `endless` |
| 2 | 1 | `1` |

## Самостоятельная работа 3 — вложенные квадратные корни

Составьте программу, которая рекурсивно вычисляет `R(n, a)` — выражение с `n` вложенными квадратными корнями. Аргументы `n` и `a` — неотрицательные целые числа. При `n = 0` результат равен `0`, а при `n > 0` он равен `√(a + R(n - 1, a))`. Для извлечения корня используйте `sqrt` из `<math.h>`, для результата — тип `double`.

Выведите таблицу трассировки. На спуске укажите уровень и значение `n`, на возврате — вычисленный результат. Например, при `n = 2` и `a = 9` базовый вызов возвращает `0`, следующий возвращает `3`, а первый — `√12 ≈ 3.4641`.

## Самостоятельная работа 4 — числа Пелля

Первое число Пелля равно `1`, второе равно `2`, а каждое следующее равно удвоенному предыдущему плюс число перед ним. Иными словами, `P(1) = 1`, `P(2) = 2`, а при `k ≥ 3` выполняется `P(k) = 2 × P(k - 1) + P(k - 2)`. Первые пять чисел — `1, 2, 5, 12, 29`.

1. Напишите рекурсивную функцию, которая находит `k`-е число Пелля. На вход подаётся положительное целое `k`. Используйте тип `long` и проверяйте, помещается ли результат в него, до выполнения умножения и сложения. Верхняя граница типа доступна как `LONG_MAX` из `<limits.h>`.
2. Для небольшого `k` выведите таблицу трассировки. Покажите уровень, аргумент на спуске и результат каждого вызова на возврате. В части спуска располагайте уровни от первого к самому глубокому, в части возврата — в обратном порядке. Вызовы одного уровня выводите подряд, каждый на своей строке.

При проверке результата выведите только `P(k)` или `!`, если число не представимо типом `long`. Например, при `k = 4` результат равен `12`.

Пример группировки вызовов для `k = 4`. Столбец спуска читайте сверху вниз, а столбец возврата — снизу вверх по уровням.

| Уровень | Рекурсивный спуск | Рекурсивный возврат |
| ---: | --- | --- |
| 0 | `P(4)` | `12` |
| 1 | `P(3)` | `5` |
| 1 | `P(2)` | `2` |
| 2 | `P(2)` | `2` |
| 2 | `P(1)` | `1` |

В таблице вызовы сгруппированы по уровням. В этом примере сначала вычисляем `P(k - 1)`, затем `P(k - 2)`. Вызов `P(3)` завершает все свои вложенные вызовы и возвращает `5`, после чего второй вызов из `P(4)` сразу возвращает `2`.

Для больших `k` можно вычислять числа в порядке возрастания индекса и передавать в рекурсивный вызов два последних значения. Тогда проверка диапазона сработает сразу, как только очередное число перестанет помещаться в `long`.
