# Занятие 5. Массивы и арифметика указателей

На прошлом занятии мы познакомились с указателями и научились изменять объекты через их адреса. Сегодня рассмотрим массивы, их расположение в памяти, связь индексации с указателями и передачу массивов в функции.

На этом занятии используем только массивы фиксированного размера. Динамическое выделение памяти и полноценную работу со строками рассмотрим позднее.

## Что такое массив

**Массив** — это последовательность элементов одного типа, расположенных в памяти друг за другом.

```c
int numbers[5];
```

Эта строка создаёт массив из пяти элементов типа `int`.

Элементы нумеруются с нуля:

```text
Индекс:       0       1       2       3       4
          +-------+-------+-------+-------+-------+
numbers:  |       |       |       |       |       |
          +-------+-------+-------+-------+-------+
```

Для массива из пяти элементов допустимы индексы от `0` до `4`. Обращение к элементу с индексом `5`, отрицательным индексом или любым другим индексом за границами массива приводит к неопределённому поведению.

Компилятор не обязан проверять границы массива во время выполнения программы.

## Инициализация массива

Все элементы можно указать при объявлении:

```c
int numbers[5] = {10, 20, 30, 40, 50};
```

Если инициализатор содержит меньше значений, оставшиеся элементы заполняются нулями:

```c
int numbers[5] = {10, 20};
```

Полученный массив:

```text
10 20 0 0 0
```

Распространённая запись для обнуления всего массива:

```c
int numbers[5] = {0};
```

Размер можно не указывать, если компилятор способен определить его по инициализатору:

```c
int numbers[] = {10, 20, 30, 40, 50};
```

В этом случае создаётся массив из пяти элементов.

## Индексация

Запись значения в выбранный элемент:

```c
numbers[0] = 10;
numbers[1] = 20;
```

Чтение значения:

```c
printf("%d\n", numbers[0]);
```

Для обработки всех элементов удобно использовать цикл:

```c
for (int index = 0; index < 5; index++){
    printf("numbers[%d] = %d\n", index, numbers[index]);
}
```

Условие содержит строгое сравнение `index < 5`. При значении `index == 5` цикл должен завершиться, потому что элемента `numbers[5]` не существует.

## Размер массива и количество элементов

Оператор `sizeof` возвращает размер объекта в байтах:

```c
int numbers[] = {10, 20, 30, 40, 50};

printf("Array size: %zu bytes\n", sizeof(numbers));
printf("Element size: %zu bytes\n", sizeof(numbers[0]));
```

Количество элементов вычисляется делением размера всего массива на размер одного элемента:

```c
int count = sizeof(numbers) / sizeof(numbers[0]);
```

Эта формула не зависит от конкретного размера типа `int`.

Полный пример:

```c
#include <stdio.h>


int main(){
    int numbers[] = {10, 20, 30, 40, 50};
    int count = sizeof(numbers) / sizeof(numbers[0]);

    printf("Array size: %zu bytes\n", sizeof(numbers));
    printf("Element size: %zu bytes\n", sizeof(numbers[0]));
    printf("Number of elements: %d\n", count);

    for (int index = 0; index < count; index++){
        printf("numbers[%d] = %d\n", index, numbers[index]);
    }

    return 0;
}
```

Формула работает там, где `numbers` является самим массивом. После передачи массива в функцию параметр будет вести себя как указатель, и `sizeof` больше не позволит определить количество элементов исходного массива.

## Массив и указатель

Имя массива в большинстве выражений преобразуется в указатель на первый элемент:

```c
int numbers[] = {10, 20, 30, 40, 50};
int *pointer = numbers;
```

После присваивания `pointer` указывает на `numbers[0]`.

```text
Индекс:       0       1       2       3       4
          +-------+-------+-------+-------+-------+
numbers:  |  10   |  20   |  30   |  40   |  50   |
          +-------+-------+-------+-------+-------+
              ↑
           pointer
```

Однако массив и указатель остаются разными сущностями:

- массив содержит все свои элементы;
- указатель содержит адрес одного элемента;
- размер массива зависит от количества и размера элементов;
- размер указателя не зависит от количества элементов массива;
- указателю можно присвоить другой адрес;
- имя массива нельзя переместить на другой объект присваиванием.

### Различие `sizeof` для массива и указателя

```c
#include <stdio.h>


int main(){
    int numbers[] = {10, 20, 30, 40, 50};
    int *pointer = numbers;

    printf("sizeof(numbers): %zu\n", sizeof(numbers));
    printf("sizeof(pointer): %zu\n", sizeof(pointer));
    printf("sizeof(numbers[0]): %zu\n", sizeof(numbers[0]));

    int count = sizeof(numbers) / sizeof(numbers[0]);

    printf("Number of elements: %d\n", count);

    return 0;
}
```

На распространённой 64-битной системе, где `int` занимает четыре байта, можно получить:

```text
sizeof(numbers): 20
sizeof(pointer): 8
sizeof(numbers[0]): 4
Number of elements: 5
```

Конкретные размеры зависят от платформы. Существенно не само число, а различие: `sizeof(numbers)` описывает весь массив, а `sizeof(pointer)` — только переменную, хранящую адрес.

Исключениями из обычного преобразования имени массива в указатель являются, в частности, использование имени массива как операнда `sizeof` и получение адреса всего массива оператором `&`.

## Индексация и арифметика указателей

Индексная запись связана с операциями над указателями:

```c
numbers[index] = *(numbers + index)
```

Оба выражения обращаются к одному элементу.

Если `pointer` указывает на элемент типа `int`, прибавление единицы перемещает его к следующему элементу `int`, а не к следующему байту.

```c
#include <stdio.h>


int main(){
    int numbers[] = {10, 20, 30, 40, 50};
    int *pointer = numbers;

    printf("numbers[2]: %d\n", numbers[2]);
    printf("*(numbers + 2): %d\n", *(numbers + 2));
    printf("pointer[2]: %d\n", pointer[2]);
    printf("*(pointer + 2): %d\n", *(pointer + 2));

    printf("*pointer: %d\n", *pointer);

    pointer++;
    printf("After pointer++: %d\n", *pointer);

    pointer += 2;
    printf("After pointer += 2: %d\n", *pointer);

    pointer--;
    printf("After pointer--: %d\n", *pointer);

    return 0;
}
```

Результат перемещений:

```text
Начало:              pointer указывает на numbers[0]
После pointer++:     pointer указывает на numbers[1]
После pointer += 2:  pointer указывает на numbers[3]
После pointer--:     pointer указывает на numbers[2]
```

Арифметика указателей определена только относительно элементов одного массива. Нельзя безопасно перемещать указатель за допустимый диапазон и обращаться по полученному адресу.

## Указатель на позицию после массива

Разрешено получить указатель на позицию сразу после последнего элемента:

```c
int *end = numbers + count;
```

Для массива из пяти элементов:

```text
Индекс:       0       1       2       3       4
          +-------+-------+-------+-------+-------+
numbers:  |  10   |  20   |  30   |  40   |  50   |
          +-------+-------+-------+-------+-------+
              ↑                                       ↑
           numbers                                    end
```

`end` не указывает на существующий элемент. Его можно использовать для сравнения и определения момента завершения обхода, но нельзя разыменовывать:

```c
*end
```

Такое обращение приводит к неопределённому поведению.

## Обход массива указателем

```c
#include <stdio.h>


int main(){
    int numbers[] = {10, 20, 30, 40, 50};
    int count = sizeof(numbers) / sizeof(numbers[0]);

    int *end = numbers + count;

    for (int *current = numbers; current != end; current++){
        printf("%d\n", *current);
    }

    return 0;
}
```

На каждой итерации:

1. `current` указывает на очередной элемент.
2. `*current` получает значение элемента.
3. `current++` перемещает указатель к следующему элементу.
4. Цикл завершается, когда `current` становится равен `end`.

Сравнение указателей в таком виде допустимо, потому что оба указателя относятся к одному массиву.

Ту же задачу можно решить индексным циклом. Индексация обычно проще читается, а обход указателем помогает понять устройство массива и интерфейсы функций языка Си.

## Изменение элементов через указатель

Разыменованный указатель позволяет изменить элемент исходного массива:

```c
#include <stdio.h>


int main(){
    int numbers[] = {1, 2, 3, 4, 5};
    int count = sizeof(numbers) / sizeof(numbers[0]);

    int *end = numbers + count;

    for (int *current = numbers; current != end; current++){
        *current *= 2;
    }

    for (int index = 0; index < count; index++){
        printf("%d ", numbers[index]);
    }

    printf("\n");

    return 0;
}
```

После выполнения цикла массив содержит:

```text
2 4 6 8 10
```

## Передача массива в функцию

Массив можно передать в функцию, указав параметр с квадратными скобками:

```c
void print_array(const int numbers[], int count);
```

Для параметра функции эта запись эквивалентна указателю:

```c
void print_array(const int *numbers, int count);
```

Функция получает адрес первого элемента, но не получает количество элементов автоматически. Поэтому размер передаётся отдельным параметром `count`.

Внутри функции параметр `numbers` является указателем. Выражение `sizeof(numbers)` вернёт размер указателя, а не размер исходного массива.

Если функция должна только читать элементы, используется `const`:

```c
void print_array(const int numbers[], int count);
```

Через такой параметр функция не может изменять элементы массива.

Если функция должна изменять элементы, `const` не указывается:

```c
void multiply_elements(int numbers[], int count, int multiplier);
```

## Многомерные массивы

Массив может содержать другие массивы. Например, двумерный массив удобно представить как таблицу или матрицу:

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

Первый индекс выбирает строку, второй — столбец:

```c
matrix[1][2]
```

Это выражение обращается к значению `6`.

Краткий пример вывода матрицы:

```c
#include <stdio.h>


int main(){
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    for (int row = 0; row < 2; row++){
        for (int column = 0; column < 3; column++){
            printf("%d ", matrix[row][column]);
        }

        printf("\n");
    }

    return 0;
}
```

Двумерный массив является массивом строк, каждая из которых сама является массивом. Строки располагаются в памяти последовательно.

Массив символов также может иметь два измерения:

```c
char colors[3][8] = {
    "red",
    "green",
    "blue"
};
```

Здесь создан массив из трёх массивов символов. Правила устройства и обработки строк будут рассмотрены на отдельном занятии.

## Самостоятельная работа 1 — функции обработки массива

Реализуйте функции, прототипы которых приведены ниже. Готовая функция `main` показывает требуемый порядок их использования.

```c
#include <stdio.h>

#define ARRAY_SIZE 5


void input_array(int numbers[], int count);
void print_array(const int numbers[], int count);
int calculate_sum(const int numbers[], int count);
void multiply_elements(int numbers[], int count, int multiplier);


int main(){
    int numbers[ARRAY_SIZE];

    input_array(numbers, ARRAY_SIZE);

    printf("Original array: ");
    print_array(numbers, ARRAY_SIZE);

    printf("Sum: %d\n", calculate_sum(numbers, ARRAY_SIZE));

    multiply_elements(numbers, ARRAY_SIZE, 2);

    printf("Modified array: ");
    print_array(numbers, ARRAY_SIZE);

    return 0;
}
```

Требования:

- `input_array` вводит все элементы с клавиатуры;
- `print_array` выводит элементы в одну строку через пробел;
- `calculate_sum` возвращает сумму всех элементов;
- `multiply_elements` умножает каждый элемент на переданное число;
- функции, которые не должны изменять массив, получают его через `const`;
- количество элементов берётся только из параметра `count`.

В этом задании нельзя определять количество элементов внутри функции через `sizeof(numbers)`.

## Самостоятельная работа 2 — разворот массива указателями

Дополните программу реализациями объявленных функций.

```c
#include <stdio.h>

#define ARRAY_SIZE 8


void input_array(int numbers[], int count);
void print_array(const int numbers[], int count);
void swap(int *first, int *second);
void reverse_array(int numbers[], int count);


int main(){
    int numbers[ARRAY_SIZE];

    input_array(numbers, ARRAY_SIZE);

    printf("Original array: ");
    print_array(numbers, ARRAY_SIZE);

    reverse_array(numbers, ARRAY_SIZE);

    printf("Reversed array: ");
    print_array(numbers, ARRAY_SIZE);

    return 0;
}
```

Требования к `reverse_array`:

- не создавать второй массив;
- не использовать индексную запись внутри функции;
- создать указатель на первый элемент;
- создать указатель на последний элемент;
- реализовать функцию `swap`, которая меняет местами два значения через указатели;
- для обмена крайних элементов вызывать `swap(left, right)`;
- после обмена сдвигать указатели навстречу друг другу;
- завершить цикл, когда указатели встретились или пересеклись;
- корректно обработать массив из нуля или одного элемента.

Начальное состояние:

```text
Индекс:          0       1       2       3       4
              +-------+-------+-------+-------+-------+
Массив:       |  10   |  20   |  30   |  40   |  50   |
              +-------+-------+-------+-------+-------+
                  ↑                               ↑
                 left                           right
```

Первый вызов `swap(left, right)`:

```text
Индекс:          0       1       2       3       4
              +-------+-------+-------+-------+-------+
Массив:       |  50   |  20   |  30   |  40   |  10   |
              +-------+-------+-------+-------+-------+
                  ↑                               ↑
                 left                           right
```

После выполнения `left++` и `right--`:

```text
Индекс:          0       1       2       3       4
              +-------+-------+-------+-------+-------+
Массив:       |  50   |  20   |  30   |  40   |  10   |
              +-------+-------+-------+-------+-------+
                          ↑               ↑
                         left           right
```

Второй вызов `swap(left, right)`:

```text
Индекс:          0       1       2       3       4
              +-------+-------+-------+-------+-------+
Массив:       |  50   |  40   |  30   |  20   |  10   |
              +-------+-------+-------+-------+-------+
                          ↑               ↑
                         left           right
```

После следующего сдвига оба указателя достигают среднего элемента:

```text
Индекс:          0       1       2       3       4
              +-------+-------+-------+-------+-------+
Массив:       |  50   |  40   |  30   |  20   |  10   |
              +-------+-------+-------+-------+-------+
                                  ↑
                             left и right
```

Условие продолжения цикла становится ложным. Средний элемент уже находится на своём месте, поэтому обменивать его не нужно.
